# Pocket Linux: проверка переносимой основы

Исторический отчёт консольного прототипа. Он предшествует полной сборке Debian-LXQt; актуальная карта комплекта находится в ../README.md, статусы работ — в корневом Beads (wcp-jaa). Оценки и ограничения ниже относятся к тому этапу.

Здесь находится самостоятельный технический прототип Debian внутри Windows. Проверены внешний сетевой процесс вместо второй VM, запрет прямого обхода прокси и работа с Windows-файлами. Это ещё не готовая редакция с LXQt и лаунчером.

Итоговая совместная проверка в TCG: **36 из 36 условий выполнены**, включая операции с Windows-папкой во время обрыва прокси. Отдельные сетевые проверки WHPX и TCG: по 30 из 30. Адаптеры и IPv4-маршруты Windows совпали с исходным снимком; тестовые процессы завершены. Машиночитаемые доказательства: `evidence/combined-tcg/result.json`, `evidence/tests-summary.json`, `evidence/network-comparison.json`.

## Что находится в папке

- `runtime/` — скопированные переносимые QEMU, Python и файловый сервер. Их файлы проверены по SHA256; установки в Windows нет.
- `images/` — официальный исходный Debian 13.7, проверенный по SHA512. Испытания создают отдельные диски изменений, исходный образ не изменяется.
- `prototype/PocketNet.exe` — сетевой процесс Windows, без драйвера, TUN, службы и системного прокси.
- `src/netproxy/` — его исходники, закреплённые зависимости и проверки.
- `prototype/guest/`, `prototype/fixture/`, `prototype/files/` — воспроизводимые испытания Linux, прокси и общих папок.
- `docs/STACK.md` — выбранный стек, устройство папок, правила общей оболочки и ограничения.
- `evidence/` — измерения и результаты испытаний. Текущий статус разработки хранится в корневом Beads, задача `wcp-i5i`.

## Повторение проверки

`Check-Network.cmd` запускает программный режим QEMU TCG, без WHPX, установок и включения компонентов Windows. Он создаёт новую папку результатов внутри `evidence/`, запускает одноразовый Debian и локальный тестовый прокси, последовательно отключает прокси и сетевой процесс; параллельно проверяет свою новую Windows-папку через SMB. Личный прокси и личные Windows-папки не используются. Результат — `result.json` с `verdict: passed` либо `failed`; окно остаётся открытым для чтения результата. На проверенном ПК весь тест занимает несколько минут.

Если WHPX уже доступен, `Check-Network.cmd whpx` использует его для ускорения. Программа не устанавливает и не включает WHPX. Проверен один Windows-ПК с Intel i5-11600 и 16 GiB RAM; другой ПК ещё не проверен. Текущему QEMU нужны поддерживаемая Windows x64 и ASCII-короткие пути для каталогов с кириллицей; на томах без таких имён совместимость пути ещё требует решения.

Программная загрузка потребовала `q35,smm=off`: диагностика показала зацикливание эмулируемого BIOS в SMM. Эта настройка относится только к гостевой VM. Изменений BIOS и безопасности основной Windows не выполняется.

| Показатель | Результат |
|---|---:|
| Папка консольного прототипа с собственными runtime и образом | около 573 MB |
| Та же папка, упакованная в ZIP (Deflate 9), CRC проверен | 420.31 MB |
| `PocketNet.exe` | 7.46 MB |
| Сетевой процесс в испытаниях: физическая память / commit | примерно 13–19 MB / до 56 MB |
| Выделенная память тестовому Debian | 1024 MiB |
| Занятые данные внутри исходного Debian | около 616 MB |
| Загрузка до гостевого пробника с WHPX | около 9 секунд |
| Загрузка программно, без WHPX | около 50 секунд |

Это измерения консольного стенда на одном ПК. **В 573 MB папки и 420.31 MB ZIP нет рабочего стола LXQt, браузера, Claude Desktop или Claude Code.** Измерение ZIP: `evidence/archive-size.json`; 1018 файлов, проверка CRC успешна. Прежний прогноз 3–6 GB архивом и 8–15 GB после распаковки отозван: он не был основан на сборке выбранного окружения.

Для более узкого состава «Debian + LXQt + Claude Desktop + необходимые ему зависимости + переносимые средства запуска» предварительный инженерный ориентир — около 1 GB ZIP (грубо 0.8–1.2 GB). Это не измерение и не гарантия: зависимости LXQt и Desktop ещё не установлены и не упакованы. Основание оценки — измеренные 420 MB основы и официальный сжатый пакет Desktop около 170 MB, с запасом на графическое окружение, библиотеки и различия сжатия. Размеры пакетов не складываются в точный размер конечного ZIP. Firefox, Claude Code и дополнительные инструменты разработки в эту узкую оценку не входят; они остаются в ранее согласованном составе полного продукта. Точный размер полного комплекта пока неизвестен. Начальная память для проверки разработки — 4 GiB; фактическое потребление требует измерения.

## Граница результата

Сетевые испытания используют SOCKS5, контролируемые TCP/UDP/DNS-сервисы и доступную с Windows публичную контрольную точку, запрещённую прокси. Проверены рабочее соединение, отказ прокси, восстановление и завершение сетевого процесса. IPv6 блокируется, запросы к стороннему DNS также проходят через выбранный прокси. Отсутствие обхода подтверждено в этих сценариях, а не для любого возможного сетевого протокола и сбоя.

Существующий файловый сервер проекта проверен с Linux CIFS: чтение файла Windows, запись с кириллицей, переименование, удаление временного файла и видимость результата со стороны Windows. Это общие исходные файлы, а не две синхронизируемые копии. Семантика Linux-ссылок, прав, регистра имён и уведомлений об изменениях отличается от локального ext4; Linux-зависимости проектов лучше хранить внутри Linux.

В совместном испытании использовались два виртуальных интерфейса: основной — только к прокси-процессу, файловый — только к локальному SMB. На файловом интерфейсе нет DNS и маршрута по умолчанию. После обрыва прокси работа с файлами продолжалась, а внешний интернет оставался закрытым.

Существующий VPN или другие маршруты основной Windows сохраняются. Соединение сетевого процесса с выбранным прокси следует этим маршрутам; удаление второй VM само по себе не обходит уже включённый VPN хоста.

В прототипе TCP-сеанс ограничен тремя минутами, UDP-сеанс — 20 секундами; это стенд, а не сетевой компонент для повседневной разработки. Настоящие внешние прокси, Hysteria2/HTTP/HTTPS-профили, полный LXQt-образ и общий WPF-лаунчер здесь ещё не приняты. Внешние сервисы видят адрес выхода прокси; гарантии его нераспознаваемости нет.

## Лицензии

Исходники прототипа находятся рядом с EXE. Тексты лицензий зависимостей — в `third-party/`, лицензии QEMU/Python/SMBLibrary — также в соответствующих runtime-каталогах. Этот каталог не опубликован как готовый выпуск.
