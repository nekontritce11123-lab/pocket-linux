# Pocket Linux: изолированный прототип

Владелец 25.10.2026 разрешил отдельную папку Pocket Linux внутри этого проекта.
Здесь проверяется Debian с LXQt и внешний сетевой процесс Windows вместо второй VM.
Работа ограничена этой папкой и служебной `_temp/2026-10-25-pocket-linux`.
Исходники и действующие копии Pocket Windows не изменять. Общий трекер — корневой Beads, задача wcp-i5i; новой базы и отдельного статусного TODO не создавать.

Никаких установщиков, драйверов, служб, WSL, новых адаптеров и изменений маршрутов/Firewall Windows. Сборочные инструменты допускаются только как распакованные файлы в служебной папке, конечному пользователю они не нужны.
QEMU рабочего гостя имеет только соединение с сетевым процессом; обычный внешний QEMU user NAT запрещён. Канал выбранных Windows-папок отдельно ограничен локальным SMB.
Клиент прокси и его секреты не попадают в рабочий Linux. Прямой fallback запрещён, включая DNS и IPv6. Не обещать нераспознаваемость выходного IP внешними сервисами.
Дизайн WPF Launcher сохраняется. Продуктовые изменения общей оболочки должны впоследствии применяться согласованно к обеим редакциям; здесь оболочка не переписывается.
Прототип и результаты проверок не являются готовым пользовательским выпуском.

Уточнение владельца 25.10.2026: внешний вид LXQt не принят. Удобство и цельное современное оформление,
похожее по привычкам на Windows 11, важнее минимизации каждого мегабайта; реальный вес и RAM всё равно измерять.
В обычной работе не должно быть запросов пароля Linux: вход, блокировка экрана, хранилище ключей Claude,
локальные административные действия. Это относится только к изолированному гостю; пароли аккаунтов сервисов
и защиту Windows не менять. Не сбрасывать существующие пользовательские ключи; новый режим готовить в чистой копии.
