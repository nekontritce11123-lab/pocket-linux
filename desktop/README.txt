Pocket Linux — проверочная переносимая сборка

Распакуй всю папку на диск NTFS и открой Launcher.exe.
Установка программ, драйверов, служб и новых сетевых адаптеров в Windows не нужна.
При первом запуске лаунчер распакует свои компоненты в эту же папку.
Пакет восстановления остаётся рядом; повторно скачивать компоненты не требуется.

Внутри: Debian 13, рабочий стол KDE Plasma с оформлением Breeze,
официальные Claude Desktop и Claude Code, Firefox ESR, Git, Python 3 и curl.
Русская и английская раскладки переключаются Alt+Shift.

Для интернета добавь своё подключение Hysteria2, SOCKS5, HTTP или HTTPS
с IPv4 или именем сервера. Без выбранного подключения Linux запускается без интернета.
Для HTTP/HTTPS защищённый DNS Cloudflare проходит через выбранный прокси.
При остановке прокси прямой запасной выход отсутствует. Сеть основной Windows
не переключается. Сайты видят IP сервера; распознавание этого IP сервисами
зависит от самого сервера и не исключается программой.

Начальные настройки: 2 ГБ памяти, 2 процессора, экран 1280 × 800.
Память и размер экрана можно изменить в «Характеристиках».
Полный экран переключается Ctrl+Alt+F, освобождение мыши — Ctrl+Alt+G.
Используется уже доступное ускорение Windows. Если его нет, QEMU работает
программно — запуск и приложения будут ощутимо медленнее, установки не нужны.

Кнопка «Выключить Linux» оставляет панель открытой. В трее есть команда
«Выключить Linux и выйти»: она закрывает панель после завершения сеанса.
Повторный запуск Launcher.exe открывает уже работающую панель этой копии.
Если штатное выключение не завершилось за две минуты, доступно отдельное
принудительное завершение с подтверждением. Оно может потерять несохранённые
данные. При неподтверждённой принадлежности процесса программа его сохраняет.

Дождись выключения Linux перед перемещением папки или извлечением диска.
Файл linux.qcow2 хранит систему, программы и личные файлы Linux и растёт
по мере работы. Для резервной копии копируй папку только после выключения.

Пароль прокси сохраняется защищённым для текущего пользователя Windows.
После переноса на другой ПК пароль нужно ввести заново. Общий ZIP не содержит
личных подключений, аккаунтов Claude или временных настроек проверки.

Общий буфер переносит текст между Windows и Linux. Его можно выключить
в «Характеристиках». Изображения и файлы через буфер не передаются.
Для файлов включи «Файлы ПК в Linux», выбери папки или «Все диски».
Открой «Файлы Windows» на рабочем столе Linux: выбранные папки обозначаются
PC_01, PC_02; диски — PC_C, PC_D и так далее. Это исходные файлы Windows:
изменения и удаления сразу действуют с обеих сторон, отдельной копии нет.
Служебные папки комплекта и автозагрузка Windows защищены от доступа.
Linux-окружения .venv, зависимости с символьными ссылками и исполняемыми
правами удобнее создавать в домашней папке Linux; общие папки сохраняют
ограничения имён и прав Windows.

Пароли самого Linux убраны: автоматический вход, пустые пароли пользователя
и администратора, системные изменения и установка программ без пароля.
Автоматическая блокировка экрана отключена. Хранилище ключей приложений
создаётся без пароля и не должно запрашивать его при запуске или перезагрузке.
Это означает полные права внутри гостя и отсутствие шифрования его токенов:
человек с доступом к папке виртуальной машины может получить эти данные.
Защита и учётная запись основной Windows не меняются.
Вход в аккаунт Claude и другие сайты выполняется тобой — это отдельные аккаунты.
Автообновление всего Pocket Linux пока не опубликовано; Windows-канал не используется.
