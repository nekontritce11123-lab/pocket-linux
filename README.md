# Pocket Linux

Проверочная переносимая сборка Debian 13 с KDE Plasma, Claude Desktop, Claude Code и Firefox ESR внутри Windows.

Актуальный комплект — **Pocket-Linux-2026.10.25.8.zip**, **1 576 179 102 байт** (около 1,58 ГБ). Он собран из чистого общего Plasma-образа, без личных подключений, аккаунтов и временных настроек проверки.

SHA256 архива:

```text
a2cebe059db04284115293fa99d90eb0e68e50e47a95270e66e581e3c5bb9319
```

Распакуй архив целиком в доступную для записи папку на NTFS и открой **Launcher.exe**. При первом запуске лаунчер распакует компоненты рядом с собой. В Windows ничего устанавливать не нужно. Подробная [инструкция пользователя](desktop/README.txt) входит в комплект как `README.txt`.

Linux можно запустить **без выбранного подключения**, с рабочим столом без интернета. Для доступа к сети добавь своё подключение Hysteria2, SOCKS5, HTTP или HTTPS. Сетевое соединение обеспечивает **PocketNet**, отдельный процесс Windows: второй VM, WSL, драйверов и новых сетевых адаптеров нет. Сеть основной Windows не переключается; при недоступности прокси прямой запасной выход не открывается.

Настройки сохраняются перед запуском и обычным закрытием панели; изменения ресурсов применяются к следующему сеансу. Повторный запуск `Launcher.exe` возвращает уже работающую панель этой копии. «Выключить Linux» оставляет панель открытой, а команда трея **«Выключить Linux и выйти»** закрывает её после завершения сеанса.

После тайм-аута штатного выключения может появиться отдельное принудительное завершение с явным подтверждением. Оно может потерять несохранённые данные и повредить диск гостя; без подтверждённой принадлежности процесса программа его сохраняет. Перед переносом папки или резервным копированием дождись выключения Linux.

Карта исходников и сборки:

- `launcher-wpf/`, `ui/`, `scripts/`, `desktop/`, `src/` — исходники лаунчера, управления и сетевого процесса.
- `build/`, `tests/` — сборка и проверки.
- `runtime/`, `images/`, `prototype/` — сборочные компоненты и отдельный сетевой стенд.
- `evidence/`, `third-party/`, `docs/` — доказательства проверок, лицензии и описание решений.

Системные пароли Linux убраны: вход, права администратора и хранилище ключей работают без пароля.

Хранилище без пароля не шифрует токены приложений: доступ к папке виртуальной машины означает доступ к этим данным. Пароли аккаунтов Claude и сайтов остаются отдельными от Linux.

Автообновление Pocket Linux отключено; Windows-канал обновлений не используется. Сборка остаётся проверочной: работа онлайн и принудительное завершение ещё требуют полной живой приёмки. Описание основы и архитектурных ограничений — в [документации прототипа](docs/PROTOTYPE-2026-10-25.md).
