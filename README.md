# Pocket Linux

Проверочная переносимая сборка Debian 13 с KDE Plasma, Claude Desktop, Claude Code и Firefox ESR внутри Windows.

Открой **Debian-Plasma-Final/Launcher.exe**. В локальной копии сохранены твои данные, выбранный тестовый VPS и общая папка **Общие файлы**. В распространяемом архиве личных подключений нет. Системные пароли Linux убраны: вход, права администратора и хранилище ключей работают без пароля.

- `Debian-Plasma-Final/` — актуальный самостоятельный комплект для запуска; подробности в `Debian-Plasma-Final/README.txt`.
- `Pocket-Linux-Debian-Plasma-final.zip` и `.zip.sha256` — актуальный архив и контрольная сумма. Измерения — в соседнем `.size.json`.
- `Debian-Plasma/` и архив `preview` — сохранённая предыдущая копия до финального исправления лаунчера и буфера.
- `Debian-LXQt/` и архив LXQt — сохранённый предыдущий вариант, внешний вид которого не принят.
- `Общие файлы/` — выбранная Windows-папка локальной копии, доступная из ярлыка «Файлы Windows» в Linux.
- `launcher-wpf/`, `ui/`, `scripts/`, `desktop/`, `src/` — исходники лаунчера, управления и сетевого процесса.
- `build/`, `tests/` — сборка и проверки.
- `runtime/`, `images/`, `prototype/` — сборочные компоненты и отдельный сетевой стенд.
- `evidence/`, `third-party/`, `docs/` — доказательства проверок, лицензии и описание решений.

В Windows ничего устанавливать не нужно. При первом открытии архива лаунчер распаковывает компоненты рядом с собой. Папка должна находиться на NTFS; перед переносом нужно штатно выключить Linux.

Хранилище без пароля не шифрует токены приложений: доступ к папке виртуальной машины означает доступ к этим данным. Пароли аккаунтов Claude и сайтов остаются отдельными от Linux.

Канал обновлений Linux пока не опубликован. Статус работы хранится только в общем Beads: `wcp-20e`; результаты финальной проверки и сравнение лаунчеров — в `evidence/plasma-final/`. Исторический отчёт основы — `docs/PROTOTYPE-2026-10-25.md`.
